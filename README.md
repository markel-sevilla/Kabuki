# Kabuki
Kabuki is an OpenGL 3.0 based lightweight library written in C++20/23. The main idea is to abstract OpenGl and make it easy for a person to start rendering medium to big scenes

## Features

- Modern OpenGL
- Shader management
- Vertex and Index Buffers
- Vertex Array Objects
- Texture loading
- Camera abstraction
- Deferred rendering API
- Lighting and shadows
- Decals
- PBR
- Ambient Occlussion
- Debug Rendering
- Picking with Kd Trees and GJK
- BVHs
- Header-only utilities where appropriate

## Dependencies

- OpenGL
- GLFW
- GLAD
- GLM
